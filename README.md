# 🎁 Wishlist de Cumpleaños


Esta plantilla te permite crear tu propia wishlist interactiva para que tus amigas puedan compartir sus gustos y preferencias, ayudándote a elegir un regalo que realmente les encante.

Desarrollada con **HTML, CSS, JavaScript, Google Sheets y Google Apps Script**, es un proyecto personal que puedes descargar, personalizar y adaptar a tu estilo.

## ✨ ¿Qué puedes hacer?

- Personalizar el diseño, los colores y los textos.
- Adaptar las preguntas y las opciones a tus gustos.
- Guardar las respuestas en tu propia hoja de Google Sheets.
- Publicar tu wishlist en internet para compartirla mediante un enlace.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- Google Sheets
- Google Apps Script

## 🚀 ¿Cómo utilizar la plantilla?

**1. Descarga el proyecto**

Descarga el repositorio como ZIP desde GitHub y extrae los archivos.

**2. Personaliza tu wishlist**

Modifica los textos, las preguntas, las opciones y los estilos según tus preferencias.

**3. Configura Google Sheets**

Crea tu propia hoja de cálculo y configura Google Apps Script para almacenar las respuestas. Sigue el tutorial de configuración para conectar ambos servicios.

**4. Publica tu página**

Utiliza un servicio de alojamiento web compatible con HTML, CSS y JavaScript, como GitHub Pages, para obtener un enlace público.

**5. Comparte tu wishlist**

Envía el enlace a tus amigas para que puedan completar el formulario.
